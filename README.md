# BI App

MVP de banca móvil 100 % digital y personalizada, construido con Flutter + Firebase (plan
Spark, costo cero) como prueba técnica Senior Front-End.

## Diseño

El proyecto sigue un flujo de especificación dirigida con Spec Kit:

- Constitución del proyecto: [`.specify/memory/constitution.md`](.specify/memory/constitution.md)
- Especificación, plan, contratos y tareas: [`specs/001-digital-banking-mvp/`](specs/001-digital-banking-mvp/)
- Guía de configuración y validación: [`quickstart.md`](specs/001-digital-banking-mvp/quickstart.md)

## Inicio rápido

```bash
flutter pub get
flutter run
flutter test
```
